Chalk Bag Illustrator - Custom Product Design Tool


Overview

This project is a web-based utility designed to allow customers to visually customize products (specifically, chalk bags for climbers) before placing an order.

The tool provides an interactive frontend experience for design, followed by a robust backend integration to capture customer data and instantly log it into a centralized database (Google Sheets) for streamlined order processing.

It demonstrates proficiency in client-side scripting (JavaScript) for rich UI manipulation and server-side scripting (PHP) for form handling and cloud integration.

Key Features

- Interactive Visual Customization: Provides a dynamic, visual interface (HTML/CSS/JavaScript) where users can preview real-time changes to colors, materials, and design elements.
- Client-Side Logic: Handles all design constraints and rules on the client side, ensuring the final submission is valid and ready for production.
- Form Data Capture: Collects all necessary customization details, contact information, and order specifics.
- Google Sheets Integration (Serverless Back-End): Utilizes a custom PHP script to securely process the form submission and write the data directly into a designated Google Sheet (acting as a simple, centralized database).
- Cross-Platform Accessibility: Optimized for desktop & mobile web browsers.
